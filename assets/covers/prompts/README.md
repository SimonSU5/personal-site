# 封面图提示词索引

本目录存放各篇笔记/作品封面图的**生成提示词**，一份封面对应一个 `.md` 文件。

## 适用规范

本组 18 篇均为**政企运维 / 网络工程 / 企业项目 / 故障排障**类内容，统一采用仓库 README 中的
**「工业运维类技术博客封面统一设计原则 · 写实工业风」**（不采用协议笔记的极简科技风）。

核心要点（详见 README）：
- 16:9 横版，**纯无文字 / 无水印 / 无 LOGO**；
- 暗调高级基调，深黑 / 冷灰 / 金属银，低饱和冷调；
- **虚实结合**：底层为行业写实场景（远景全景），上层叠加半透明发光网络拓扑线条 / 节点 / 数据流；
- **排障类**点缀**低饱和红色微光故障点**；**跨省 / 双跨 / 专线类**必做**双向平行双线链路**；
- 电影级景深、材质写实、元素克制。

> 风格基准：`某大型制造企业跨省双跨排障-封面.png`（已定稿，提示词见对应文件）。

## 使用方式

1. 打开对应 `.md`，复制「正向提示词」+「负向提示词」喂给图像生成模型（16:9）。
2. 生成后将图片以「建议封面文件名」保存到 `assets/covers/`。
3. 把文章 frontmatter 的 `cover:` 改为该路径（如 `assets/covers/公安单位专线卫士FTTO组网-封面.png`）。

> 已有封面的 5 篇（4 作品 + 双跨排障）frontmatter 已指向专属封面；其余 13 篇目前仍指向占位封面，生成后需替换。

# 封面图提示词索引

本目录存放各篇笔记/作品封面图的**生成提示词**，一份封面对应一个 `.md` 文件。

## 适用规范

本组 18 篇均为**政企运维 / 网络工程 / 企业项目 / 故障排障**类内容，统一采用仓库 README 中的
**「工业运维类技术博客封面统一设计原则 · 写实工业风」**（不采用协议笔记的极简科技风）。

核心要点（详见 README）：
- 16:9 横版，**纯无文字 / 无水印 / 无 LOGO**；
- 暗调高级基调，深黑 / 冷灰 / 金属银，低饱和冷调；
- **虚实结合**：底层为行业写实场景（远景全景），上层叠加半透明发光网络拓扑线条 / 节点 / 数据流；
- **排障类**点缀**低饱和红色微光故障点**；**跨省 / 双跨 / 专线类**必做**双向平行双线链路**；
- 电影级景深、材质写实、元素克制。

> 风格基准：`某大型制造企业跨省双跨排障-封面.png`（已定稿，提示词见对应文件）。

## 使用方式

1. 打开对应 `.md`，复制「正向提示词」+「负向提示词」喂给图像生成模型（16:9）。
2. 生成后将图片以「建议封面文件名」保存到 `assets/covers/`。
3. 把文章 frontmatter 的 `cover:` 改为该路径（如 `assets/covers/公安单位专线卫士FTTO组网-封面.png`）。

> 已有封面的 5 篇（4 作品 + 双跨排障）frontmatter 已指向专属封面；其余 13 篇目前仍指向占位封面，生成后需替换。

# 案例

## 某大型制造企业跨省双跨排障 · 封面图提示词

- 建议封面文件名：`assets/covers/某大型制造企业跨省双跨排障-封面.png`
- 对应文章：blogs/网络维护-某大型制造企业跨省双跨排障.md（网络维护·排障）
- 适用规范：README「工业运维类技术博客封面统一设计原则·写实工业风」
- 风格基准：参照已定稿的 `某大型制造企业跨省双跨排障-封面.png`（深色工业实景 + 半透明发光网络拓扑叠加 + 局部红色微光）
- 画幅：16:9 横版　|　文字：纯无文字、无水印、无 LOGO

### 正向提示词（Positive Prompt）

16:9 横版构图，写实工业科技风格封面，画面纯无文字、无水印、无 LOGO、无任何标注。暗调高级基调，以深黑、冷灰、金属银为主色，整体低饱和冷调，拒绝暖色与高饱和亮色。电影级景深光影，背景轻微虚化、主体清晰锐利，保留金属、钢结构、设备与建筑的原生肌理，写实硬核、不扁平、不卡通，8K 高质感。

画面底层为大型制造/重工冶炼厂区，高炉、钢结构厂房、工业管线、烟囱与桥吊（定稿基准场景），远景/全景取景，氛围沉稳厚重，凸显企业级工程项目的规模感与专业属性。上层叠加半透明科技网络元素：柔和半透明的发光光纤拓扑线条、网络节点、双向平行的双线跨省 PTN 主备链路（双跨）、跨域网络节点、流动的数据光带，弱化 UI 感、自然融入实景而不遮挡工业主体，仅点明网络运维/组网技术属性。在双跨链路一处点缀低饱和红色微光故障点作为视觉焦点，呼应双跨不通/排障主题，无夸张特效。（本篇为整套系列的风格定稿基准）整体层次分明，明暗对比柔和，局部设备与线条微光提亮，高级耐看不刺眼。

### 负向提示词（Negative Prompt）

文字、字母、数字、水印、LOGO、签名、标注、贴纸、装饰图案、异形图标、高饱和亮色、暖色调（暖黄/暖橙/暖红）、卡通、动漫、插画、扁平化、低多边形、人物正脸特写、生活化场景、近距离人物特写、科技元素过重遮挡实景、光效杂乱刺眼、镜头光晕过曝、画面模糊、颗粒噪点过多、构图拥挤、留白失衡、变形肢体。

### 定制要点（本篇专属）

- **场景打底**：大型制造/重工冶炼厂区，高炉、钢结构厂房、工业管线、烟囱与桥吊（定稿基准场景）
- **科技链路**：双向平行的双线跨省 PTN 主备链路（双跨）、跨域网络节点
- **故障标识**：在双跨链路一处点缀低饱和红色微光故障点作为视觉焦点，呼应双跨不通/排障主题，无夸张特效。（本篇为整套系列的风格定稿基准）
- **硬性底线**：16:9、纯无文字、暗调冷色、虚实结合、材质写实、元素克制。
